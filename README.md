# Fluxzero on GitHub

Fluxzero is the European cloud for AI-built apps. This repository owns the public [organization profile](profile/README.md), the shared GitHub [brand assets](assets/brand/README.md), and the project directory below.

[Get started](https://fluxzero.io/get-started) · [How it works](https://fluxzero.io/how-it-works) · [Docs](https://fluxzero.io/docs) · [Contact](https://fluxzero.io/contact)

## Maintaining this profile

Use the rendered [Fluxzero website](https://fluxzero.io) as the source for product messaging. Keep the organization introduction accessible to product builders, and give each repository a precise explanation of its purpose. Keep technical instructions in the repositories that own them.

Use the existing website logo and wordmark. Brand exports live in versioned asset directories so README image links stay stable. Preserve upstream attribution in forks and label historical projects clearly.

Fluxzero logos and branding are all rights reserved, consistent with the website's branding policy. Each linked project's software license is defined in its own repository.
